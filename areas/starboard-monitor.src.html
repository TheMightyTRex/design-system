What changed and why
  • Monitor is kept as a page but uses the same line chart as Overview, with a table view and keyboard reading, instead of its own sparklines. Overview's time range links here as "Live".
  • Pause keeps one label and uses aria-pressed. Charts update in place, so a focused chart or open table keeps focus.
  • The processor threads become a labelled list of meters, so each value is in words, not only in a tooltip.
