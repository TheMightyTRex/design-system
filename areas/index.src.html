Boards

Every area of Starboard and Storyarr as a full page, built only from the shared component library.

  • Starboard

    An accessible dashboard for a home media server: the apps it runs, downloads, storage, disk health and backups. Plain HTML and JavaScript, using the library as it is.

    18 boards

  • Storyarr

    Follow authors and series and keep your audiobook library complete. Built with React, which wraps the library's classes in its own components.

    19 boards

What a board is

A board is one page of an app, designed with the library before it is built. Each one starts with what changed and why, then shows the whole page at desktop width, then the part that changes on a phone.

Slide-outs, menus and dialogs work, so a board can be tried as well as read. Choose an app, then a category and a board in the menu.
