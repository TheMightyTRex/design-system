What changed and why

Every book opens the same Summary slide-out on all four tabs. Today In my libraries opens a panel and the other three tabs jump to the book page.

One toolbar (design D) on every tab: view switch, search, format chips with counts, Library menu, sort. Manage connections and Save view moved from above the toolbar into its More menu; the sort note moved into the summary line.

Summary facts: Author first, then Series, then Narrated by, which links to the new narrator page.

One cover grid that follows the cover size setting, plus a List view. Add a title is a short dialog, not a form that pushes the grid down.
