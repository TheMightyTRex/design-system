What changed and why
  • The side menu (rail) is the main menu, as in Storyarr, with the five sections David named: Library, Discover, Activity, System and Settings. Header row 1 holds each section's pages; row 2 a page's own tabs, only when it has them.
  • Search is always one button away: first in the side menu under the logo, and a search icon in the header on phones, where the search box is hidden today. Both open the same search box (new in the design system: .rail__search, .site-header__search-btn).
  • Every page Starboard has today keeps its place in the table below; nothing is lost. The logo opens System, Apps, today's home page.
  • Select a section in the side menu to see its tabs.

Server name in the header

Four ways to show the server's name. Each uses the made-up name "T-Rex". The name is limited to 10 characters, so it stays short enough for the header.

The 10-character limit
  • A new field in Settings, General: Server name, hint "Shown in the header. Up to 10 characters.", with a live count ("5 of 10 characters").
  • The field stops at 10 characters (maxlength="10"), and the server trims and checks it too, so the API cannot store a longer one.
  • Empty means no server name is shown. The longer site name (up to 60 characters) stays for the browser tab and alerts.
  • Letters, numbers, spaces and hyphens. Counted as characters a person sees, so an accented letter counts once.

On phones

  • The side menu is hidden. The header shows the menu button, the logo and name, the search button and Display.
  • The search button opens the search box as a row under the header; Escape or a press outside closes it.
  • The phone menu lists the five sections with their pages (main menu and 1st level, with icons); a page's own tabs stay under the header.
