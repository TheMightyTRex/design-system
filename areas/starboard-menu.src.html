Starboard Server: T-Rex
{{i:info}}
What changed and why
  • Three names (David, 4 November 2026): the side menu on the left, the level 1 menu (header row 1: a section's pages) and the level 2 menu (header row 2: a page's own tabs, only when it has them).
  • The side menu has the logo with "Starboard" underneath, then Search, then the five sections: Library, Discover, Activity, System and Settings.
  • The level 1 menu starts with the server's own name ("T-Rex", made up here), up to 10 characters, as plain text with no icon. Screen readers hear "Server: T-Rex".
  • Search is always one button away: first in the side menu under the logo, and a search icon in the header on phones, where the search box is hidden today. Both open the same search box (new in the design system: .rail__search, .site-header__search-btn).
  • Every page Starboard has today keeps its place in the table below; nothing is lost. The logo opens System, Apps, today's home page.
  • Select a section in the side menu to see its level 1 menu, and a page there to see its level 2 menu.

Server name

Decided (David, 4 November 2026): at the start of the level 1 menu, as in the header above. On phones the header shows only the logo on the left, with no names (David, 4 November 2026); screen readers still hear "Starboard" and "Server: T-Rex".

{{i:info}}
The 10-character limit
  • A new field in Settings, General: Server name, hint "Shown in the level 1 menu. Up to 10 characters.", with a live count ("5 of 10 characters").
  • The field stops at 10 characters (maxlength="10"), and the server trims and checks it too, so the API cannot store a longer one.
  • Empty means no server name is shown. The longer site name (up to 60 characters) stays for the browser tab and alerts.
  • Letters, numbers, spaces and hyphens. Counted as characters a person sees, so an accented letter counts once.

On phones

  • The side menu is hidden. The header shows the menu button, the logo on its own (no names), the search button and Display.
  • The search button opens the search box as a row under the header; Escape or a press outside closes it.
  • The phone menu lists the five sections with their pages (side menu and level 1 menu, with icons); the level 2 menu stays under the header.
