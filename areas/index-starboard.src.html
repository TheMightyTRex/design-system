Starboard boards

An accessible dashboard for a home media server: the apps it runs, downloads, storage, disk health and backups. Plain HTML and JavaScript, using the library as it is.

18 boards2 November 2026Built only from the shared component libraryStarboard on GitHub

{{i:info}}
How to read the boards

Each board starts with what changed and why, then the full page at desktop width, then the part that changes on a phone. Select a row, card or button to open its slide-out; Escape closes it. Display in the header switches theme and text size. The audit is audit-starboard.md; components the library still lacks are in starboard-missing-components.md.

Apps, Search, Downloads and Coming up

  • {{i:menu}}
    Menu (proposal, 4 November 2026)
    The side menu with Library, Discover, Activity, System and Settings; a Search button first; where every page goes; four ways to show the server name.
  • {{i:layout-grid}}
    Apps
    Cards open an app details slide-out; Open is its own button; Updates becomes a filter chip; one summary line replaces the status pills.
  • {{i:server-cog}}
    Other services
    Same rows and slide-out as Apps; "follows" shown on the row; hints become the empty state.
  • {{i:search}}
    Search
    Add modal becomes an Add slide-out so the result stays visible; toolbar with kind chips; h2 Results with h3 items.
  • {{i:download}}
    Downloads
    Download details slide-out with messages, history and actions; rows update in place; Sort added; Pause updates keeps one label.
  • {{i:calendar-days}}
    Coming up
    Range control and filter chips (Wanted, In library, by app); each item opens a slide-out like Storyarr's calendar day panel.

System

  • {{i:gauge}}
    Overview
    Needs attention moves first with a warning slide-out; stat tiles say warnings in words; labelled time range with a Live link.
  • {{i:hard-drive}}
    Storage
    One list fullest first instead of every folder three times; folder slide-out with growth; set-up hint becomes the empty state.
  • {{i:heart-pulse}}
    Disk health
    Compact row per disk sorted by tone; wide SMART report slide-out with the full attribute table, self-tests and events.
  • {{i:chart-line}}
    Monitor
    Same line chart as Overview with a table view; Pause keeps one label; processor threads as labelled meters.
  • {{i:network}}
    Network
    "Who can open Starboard" becomes a link to Security; outside access rows open the app details slide-out.
  • {{i:archive}}
    Backup and restore
    Two sections instead of three; backup run and saved copy slide-outs; password asked once, in the confirm dialog.

Settings, Sign in and Set up

  • {{i:app-window}}
    Manage apps
    Renamed from Apps; the 17-field modal becomes a two-step add and edit slide-out; More actions menu; Remove confirms in a dialog.
  • {{i:sliders-horizontal}}
    General
    Sections with their own Save; categories become an editable list; card options are switches.
  • {{i:shield-check}}
    Security
    Three sections with h2s; Sign out everywhere and turning off network access confirm in dialogs.
  • {{i:info}}
    About and updates
    Renamed from Updates; update notice with release notes; copyable update command.
  • {{i:key-round}}
    Sign in
    Slim header with Display before signing in; error tied to the field.
  • {{i:user}}
    Set up
    Setup code first, with where to find it as its hint; Display in a slim header.
