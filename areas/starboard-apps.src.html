What changed and why
  • Each card now opens an app details slide-out (status, update, addresses, the app's own warnings, Edit). Open is its own button, so the card is no longer only a link out of Starboard.
  • Updates is no longer a separate page: an Update available filter chip and the slide-out show it. The Apps sub-menu is Apps and Other services. Settings, Apps is renamed Manage apps, so only one page is called Apps.
  • The two status pills become one summary line, announced once. The hero search is gone: the header search does the same job.
