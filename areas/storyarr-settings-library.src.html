What changed and why

Every section uses the settings rows template: cards with a heading and one line, label and explanation on the left, the control on the right.

One way to add and edit in Libraries: today the section has a popover, an inline form and modals. Now an Add server menu in the card header, and every server, library and folder edits in a slide-out (the folder picker in a wide one).

One status per server instead of two status widgets and a page notice for the test result. File naming keeps its builder; its join select grows from 22px to 44px.

One save pattern, modelled on File naming: a save bar that stays in view at the foot of the section, with Save changes, Discard changes and the save state. No more autosave next to explicit saves, or "Saved" above the form in one section and below in another.

Things with several fields open a slide-out with Save, Cancel, Test and Remove in its footer; removing always asks in a dialog.

Release notes

Version 1.10.0, 28 October 2026 · current version

Added

Narrator pages: open a narrator from any book to find every book they read in your library.

Slide-outs: book summaries, requests and connections open beside the list.

Changed

Settings: every section saves the same way, with a save bar that stays in view.

Fixed

Notifications: deleting a channel now asks first.

Database changes

Adds a narrator table. A backup is made before the upgrade; restore it from Settings, System, Upgrades.

Remove Audiobookshelf?

Storyarr stops reading its 2 libraries. Files on the disk are not touched, and you can add the server again.
