Release notes (opens in a new tab)

Updates

Updates run on the server, so the dashboard never needs access to Docker.

  • Check GitHub for new releasesOn: Starboard checks once a day and shows a notice here.

How to update

Run this on the server, in the folder you installed Starboard into:

./update.sh
  1. It backs up your settings.
  2. It installs the newest release.
  3. If the new version does not start, it goes back to the previous one.
