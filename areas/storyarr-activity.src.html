What changed and why

The heading says Activity, like the menu, instead of "Requests". Sort, Find books and Import local files leave the tab row: sort joins the toolbar and the two actions go in its More menu.

One row per request with a status chip per format and a progress bar only while downloading, instead of a table with one h2 per request and mostly empty Speed and Time left columns.

Request details open in a slide-out with the recovery timeline already expanded, preferences and reasons, and actions in a footer. Today the status chip is a 20px button that expands a table row two details blocks deep.

Sources for a request open in a wide slide-out instead of a modal inside a table cell. Withdraw is a dialog at page level. Status words follow the content guide: "In library", never "Available".
