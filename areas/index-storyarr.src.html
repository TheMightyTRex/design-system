Storyarr boards

19 boards, 2 November 2026, built only from the shared component library.

{{i:info}}
How to read the boards

Each board is a full desktop page with the rail, header row 1 and, where the page has tabs, header row 2. It starts with "What changed and why" and ends with a 390px phone preview of the part whose layout changes. Slide-outs and dialogs work: select a book, a row or an Edit button. Parts marked "Board: another tab or state of this page" show other tabs on the same board.

Components the boards needed but the library lacks are listed in storyarr-missing-components.md. The boards are generated by storyarr-gen/make.py, then tools/build.py.

Library

  • My library

    Every book opens the same Summary slide-out on all four tabs; one toolbar per tab; Author, Series, then Narrated by in the facts.

  • Following

    Tabs in header row 2, hero dropped; Follow an author and Follow settings open slide-outs; no drawer inside the detail.

  • Library review

    Item review moves from a deeply nested modal to a wide slide-out with Previous and Next; problem chips on the toolbar.

Item pages

  • Book page

    Two main actions and a More menu; tabs in row 2, including a visible Details and matching; copies, editions, releases and matching in slide-outs.

  • Author page

    Shared item header and progress bar; back link returns where you came from; books open the Summary slide-out.

  • Series page

    Selection side column becomes a sticky selection bar; Request opens a slide-out; Requests tab moves to Activity.

  • Narrator page (new)

    Every book in your library read by one narrator, plus Find more by this narrator.

Discover and search

  • Discover: For you and Browse

    Visible h1, one shelf header, Customise Discover as a slide-out; Browse on the section toolbar with Clear all.

  • Calendar

    Month is a real table; day details in the shared slide-out; one toolbar with month controls; list view on phones.

  • Search results

    One search box (the header); Where to search menu and Books, Authors, Series chips; results open the Summary slide-out.

Activity

  • Activity: Queue, Wanted, History

    Heading says Activity; one row per request; request details with the recovery timeline in a slide-out; bulk approve on Wanted.

Settings

  • Settings: General

    Display renamed from General; one save bar; notification channels edit in a slide-out and deleting one now asks first.

  • Settings: Accounts

    No third tab level; people and roles edit in slide-outs; sign-in providers move to Sign-in.

  • Settings: Sources

    Reading accounts as cards with list rows; connecting and list details in slide-outs; one home for the Hardcover token.

  • Settings: Library

    One way to add and edit servers, access and folders (slide-outs); File naming's save bar becomes the model.

  • Settings: Downloads

    Clients only in Download clients, edited in a slide-out; reserve and recovery move to Preferences; blocklist with Undo.

  • Settings: System

    Logs on the toolbar with entries in a slide-out; main upgrade setting first; restore is a dialog.

Wizards

  • Onboarding

    Shared wizard: one question per step, Continue saves, Keep the defaults and finish, connection as a dialog.

  • Upgrade wizard

    Same wizard as setup; one step per new setting; Remind me later is a quiet button.
