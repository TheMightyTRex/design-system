How to read the boards

Each board is a full desktop page with the rail, header row 1 and, where the page has tabs, header row 2. It starts with "What changed and why" and ends with a 390px phone preview of the part whose layout changes. Slide-outs and dialogs work: select a book, a row or an Edit button. Parts marked "Board: another tab or state of this page" show other tabs on the same board.

Components the boards needed but the library lacks are listed in storyarr-missing-components.md. The boards are generated by storyarr-gen/make.py, then tools/build.py.
