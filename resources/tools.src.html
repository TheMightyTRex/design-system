Tools in this repository

The scripts in the tools folder: what each one does and the command that runs it.

{{i:info}}
Before you begin:

You need Python 3 and a copy of the repository. Run every command from the repository's own folder.

Build the gallery and boards: build.py

Turns each .src.html file into the page people open. It replaces {{i:name}} with an icon and <!--ICONS--> with the icon file. Change the .src.html file, never the page it makes.

python3 tools/build.py

The pages in resources are made from resources/content. After you change one, run this before build.py:

python3 resources/make.py

Check contrast: contrast.py

Measures every text and control colour pair against WCAG 2.2 AA (Web Content Accessibility Guidelines): in all four themes, and in Light and Dark for every palette. Text needs 4.5:1, and control borders and the focus ring need 3:1. The report must end with "0 failures".

python3 tools/contrast.py > contrast-report.txt

Make the palettes: palettes.py

Writes the five colour palettes in palettes/ and the gallery's Palettes section. A palette changes only the colours. Status colours, chart series and High contrast stay the same, so their meanings never change. Run contrast.py after it.

python3 tools/palettes.py

Add an icon: icons.py

Rebuilds icons.svg from Lucide. Add the icon's Lucide name to tools/icons.txt, then run:

python3 tools/icons.py "$(tr '\n' ' ' < tools/icons.txt)"

Copy the library into the apps: sync.py

Copies tokens.css, components.css, components.js and the icons into Storyarr and Starboard, so both apps use the same components. It does not commit. Add --check to list what would change without writing anything.

python3 tools/sync.py --check
python3 tools/sync.py

By default it looks for ../starboard and ../storyarr beside this repository. To use other folders, set STARBOARD_WEB and STORYARR_SHARED, or put them in tools/paths.local.json, which git ignores:

{ "STARBOARD_WEB": "~/src/starboard/web", "STORYARR_SHARED": "~/src/storyarr/apps/web/src/shared" }

Keep private details out: check-private.sh and install-hooks.sh

check-private.sh stops a commit that would publish home network addresses, email addresses, keys, or the words in your own .private-words file (one word a line; git ignores it). install-hooks.sh runs the check before every commit in your copy. Run it once.

tools/install-hooks.sh
tools/check-private.sh
