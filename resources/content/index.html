Design resources and tools

Everything in the TRex Design System that you can use in your own work, and how to change it and test it.

The TRex Design System is the one source of the components, tokens, icons and guides for Storyarr and Starboard. It is public: you may use any of it in your own projects, under the licences on this page.

What you can use

  • Component gallery

    Every component working, in four themes and five text sizes, with the classes to copy.

  • Tokens

    Every colour, size, space and motion value as role names, in tokens.css, for Light, Dark, High contrast and High contrast dark.

  • Palettes

    Five more colour lists for a new design or site: Indigo, Forest, Plum, Ember and Graphite. Load one after tokens.css.

  • Icons

    Lucide icons as one SVG file, icons.svg. Use an icon with <use href="#i-book-open">.

  • Font

    Atkinson Hyperlegible Next, made to be clear for people with low vision, in fonts/.

  • Storyarr design boards

    Every area of Storyarr as a full page, built only from the library.

  • Starboard design boards

    Every area of Starboard as a full page, built only from the library.

Guides

The guides are in the docs folder of the repository.

GuideRead it when
Content design guideYou write any words: a button, an error, a setting, release notes
Help writing guideYou write or check help, or ask an AI assistant to
Accessibility guideYou build or test anything; it sets the floor every page must meet
Security checks guideYou release an app: the checks to run, how to sort what they find, and how to record the results
Design system guideYou lay out a page: principles, tokens, the header and page templates
Component referenceYou need a class name, or must choose between a slide-out, a dialog and a page
